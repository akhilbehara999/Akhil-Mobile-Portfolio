You are building an Android-style personal portfolio web app from scratch. 
This is NOT a traditional portfolio website. It must feel and behave like a 
native Android application running inside a browser on a mobile phone.

══════════════════════════════════════════
TECH STACK
══════════════════════════════════════════

- React 18 + TypeScript
- Tailwind CSS (utility-first, no extra component libraries)
- Recharts (for all data visualizations — Line, Bar, Pie)
- Framer Motion (for animations and micro-interactions)
- Google Fonts (for typography)
- NO external UI component libraries (no shadcn, no MUI, no Radix)

══════════════════════════════════════════
RESPONSIVE BEHAVIOR — CRITICAL
══════════════════════════════════════════

The app has two states based on viewport width:

1. MOBILE (max-width: 768px)
   → Render the full Android-style portfolio Home screen (described below)

2. TABLET + DESKTOP (min-width: 769px)
   → Replace the ENTIRE screen with a polished "Coming Soon" screen.
   → The Coming Soon screen must:
      - Use the same color system as the portfolio (warm white + #AA2222 + orange)
      - Show the name "Akhil" prominently
      - Show a short tagline: "Full mobile experience coming to tablet & desktop soon."
      - Show a subtle animated pulse or shimmer effect (no garish animations)
      - Feel premium, not like a placeholder
      - Center everything vertically and horizontally
   → Do NOT render any portfolio content on tablet/desktop viewports.

══════════════════════════════════════════
APP STATE & ROUTING
══════════════════════════════════════════

Use React useState for navigation — no React Router needed.

State: currentScreen: "home" | "workspace" | "contact"

- When currentScreen === "home": show Home scroll content + active Home nav item
- When currentScreen === "workspace": show Coming Soon screen, Workspace nav active
- When currentScreen === "contact": show Coming Soon screen, Contact nav active

The floating bottom nav always stays visible on all three states.
On Coming Soon screens, the nav still shows but Home is not active.
