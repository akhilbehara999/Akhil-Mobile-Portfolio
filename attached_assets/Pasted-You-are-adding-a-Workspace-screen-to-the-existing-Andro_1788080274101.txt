const [currentSection, setCurrentSection] = useState<SectionId>(null)

Rendering logic:
  if viewport >= 769px → <ComingSoon type="tablet" />

  else if currentScreen === "home" → <HomeScreen />
  else if currentScreen === "workspace" → <WorkspaceScreen onCardTap={(id) => { setCurrentSection(id); setCurrentScreen("section") }} />
  else if currentScreen === "section" → <SectionScreen sectionId={currentSection} onBack={() => setCurrentScreen("workspace")} />
  else if currentScreen === "contact" → <ComingSoon type="contact" onBack={() => setCurrentScreen("home")} />

BottomNav behavior on Workspace and Section screens:
  - Workspace screen: Workspace tab is active
  - Section screen: Workspace tab remains active (still inside workspace flow)
  - Tapping Home on nav from Section: goes to home, clears currentSection
  - Tapping Contact on nav from anywhere: goes to Contact Coming Soon
